<task type="auto">
  <name>Task 2: Create a smoke verifier that proves no OOM and bounded worker RAM</name>
  <files>scripts/verify_phase3_smoke.sh</files>
  <action>
Create `scripts/verify_phase3_smoke.sh` as a post-run verifier for the smoke job.

The script must accept `JOB_ID` as its first argument and optionally accept `BUDGET_MB` as a second argument, defaulting to `16384`.

Verification steps to automate inside the script:
1. Query SLURM with `sacct -j "$JOB_ID" --format=State,ExitCode --noheader` and fail unless the primary state is `COMPLETED` and exit code is `0:0`.
2. Locate the job stdout/stderr file the wrapper produced and grep for:
   - `Parallel: strategy=multicore`
   - `future.globals.onReference = 'error' enabled`
   - `ALLOCATION_REGION_FILTER=`
   - `ALLOCATION_YEAR_POST_FILTER=`
3. Locate the per-region allocation log for the targeted region and assert it contains:
   - `stage=pin_native_threads_to_one`
   - `stage=preload_models`
   - `stage=nhood_precompute`
   - `stage=parent_baseline`
   - `CGROUP`
4. Fail if any of these appear in stdout or the region log:
   - `oom-kill`
   - `MulticoreFuture interrupted`
   - `SENTINEL reason=incomplete`
5. Parse `peak_rss=` values from the region log and fail if any exceed `BUDGET_MB`.
6. Resolve the targeted posterior TIF path for the scenario/region/year filters and confirm it exists. Use a small `Rscript -e` call with `terra::rast()` to prove the output is readable.
7. Print a concise PASS summary including strategy, job state, max observed `peak_rss`, and the validated output path.

The script must return non-zero on any failed check so it can act as an automated gate. Keep the parsing grep/awk-based; no new language dependencies.
  </action>
  <verify>
    <automated>rg -n "sacct|Parallel: strategy=multicore|future\\.globals\\.onReference = 'error' enabled|stage=preload_models|stage=nhood_precompute|stage=parent_baseline|peak_rss|SENTINEL reason=incomplete|terra::rast" scripts/verify_phase3_smoke.sh</automated>
  </verify>
  <done>`scripts/verify_phase3_smoke.sh` exists and automatically checks job completion, multicore selection, strict-globals activation, parent preload evidence, absence of OOM markers, worker RSS budget, and posterior TIF readability</done>
</task>
