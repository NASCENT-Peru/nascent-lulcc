### 1. `scripts/submit_allocation_scenario.sh` (launcher, fan-out + afterok dependency) — D-04

The launcher is a **composite**: borrow the SBATCH header + per-region env-passing from `run_andes_validation.sh`, and the `afterok` dependency-submission idiom from `master_pipeline.sh`. It must (a) loop one job per region with `ALLOCATION_REGION_FILTER` set, (b) set per-region `--partition=highmem`/`fat` + `--mem` (D-02), (c) capture each region job-id and queue a dependent (`afterok:<all-region-ids>`) mosaic-assembly job (D-03).

### 2. `scripts/assemble_national_mosaic.r` (post-hoc national mosaic assembler) — D-03

The assembler lifts the existing per-timestep mosaic logic out of the worker loop and drives it post-hoc over per-region `posterior.tif`s, for **every** timestep — producing the `posterior_<year>.tif` national series.

**Core pattern — the merge/extend/write block to lift verbatim**
`src/allocation.r` (lines 1787-1810, inside `run_allocation_one_timestep`):
```r
  # Mosaic region posteriors back to full extent
  message("    Mosaicing region posteriors...")
  region_rasters <- lapply(posterior_paths, terra::rast)

  # Extend all to the full extent of the original LULC, then merge
  full_extent <- terra::ext(terra::rast(current_lulc_path))
  region_rasters <- lapply(region_rasters, function(r) {
    terra::extend(r, full_extent)
  })

  if (length(region_rasters) == 1) {
    mosaiced <- region_rasters[[1]]
  } else {
    mosaiced <- do.call(terra::merge, region_rasters)
  }

  # Save mosaiced result
  output_path <- file.path(timestep_dir, sprintf("posterior_%d.tif", year_post))
  terra::writeRaster(
    mosaiced, output_path, overwrite = TRUE,
    wopt = list(datatype = "INT2U", gdal = c("COMPRESS=LZW"))
  )
```
> Per-region posteriors the assembler must collect, per timestep:
> `outputs/simulations/{scenario}/{year}/region_{suffix}/posterior.tif`
> (the worker's return value — `src/dinamica_utils.r:861` `posterior.tif`,
> `src/allocation.r:1782` `return(posterior_path)`). The national output path
> is the **same** region-agnostic `timestep_dir/posterior_<year>.tif`
> (`src/allocation.r:1804`) — assembly is now the ONLY writer of that path
> (D-05). `full_extent` derives from the timestep's anterior LULC raster.

**CLI / post-hoc script shape — argument parsing + project-root + source order**
`scripts/diagnose_allocation_saturation.r` (lines 26-87) is the canonical post-hoc R-script analog: sets project root from `--file=`, sources `src/setup.r` + `src/utils.r` (+ here add `src/dinamica_utils.r`/`src/allocation.r` for terra helpers), then a small positional+flag arg parser:

### 3. `scripts/verify_allocation_run.sh` + manifest (completeness + plausibility checker) — D-08/D-08b

**Analog A — verify-script shape (state gate, marker greps, path resolution, PASS line)**
`scripts/verify_phase3_smoke.sh` (whole file, esp. lines 1-25, 27-44, 46-53, 97-104):
```bash
#!/bin/bash
set -euo pipefail
JOB_ID="$1"
# 1. sacct state/exit gate
SACCT_LINE=$(sacct -j "$JOB_ID" --format=State,ExitCode --noheader | awk 'NF {print; exit}')
JOB_STATE=$(echo "$SACCT_LINE" | awk '{print $1}'); EXIT_CODE=$(echo "$SACCT_LINE" | awk '{print $2}')
if [ "$JOB_STATE" != "COMPLETED" ] || [ "$EXIT_CODE" != "0:0" ]; then ... exit 1; fi
# 2. required stdout markers / forbidden markers (oom-kill, SENTINEL reason=incomplete)
for pattern in "ALLOCATION_REGION_FILTER=" "ALLOCATION_YEAR_POST_FILTER="; do grep -q "$pattern" "$JOB_STDOUT" || { ... exit 1; }; done
for forbidden in "oom-kill" "MulticoreFuture interrupted"; do grep -q "$forbidden" ... && exit 1; done
# 3. resolve config-derived output paths via an inline Rscript probe
readarray -t PATH_INFO < <(Rscript --vanilla -e "setwd('.'); source('src/setup.r'); cfg <- get_config(); cat(file.path(cfg[['simulation_output_dir']], '$SCENARIO', '$YEAR_POST', paste0('posterior_', '$YEAR_POST', '.tif')), '\n')")
POSTERIOR_TIF="${PATH_INFO[0]}"
# 4. existence + loadability of the posterior raster
[ -f "$POSTERIOR_TIF" ] || { ...; exit 1; }
Rscript --vanilla -e "terra::rast('$POSTERIOR_TIF'); cat('posterior-ok\n')"
# 5. single structured PASS line
echo "PASS strategy=multicore state=$JOB_STATE peak_rss_mb=$MAX_PEAK_RSS output=$POSTERIOR_TIF"
```
> Extend this to iterate the **full region × timestep matrix** (D-06): for every
> region × every `simulation_year_steps` timestep assert `posterior.tif` exists,
> is a valid GeoTIFF, and **differs from its anterior** (load both with terra,
> compare), assert the national `posterior_<year>.tif` exists per timestep,
> assert `count == regions × timesteps`, then emit `PASS` / `INCOMPLETE`.

### 4. `src/allocation.r` — D-05 per-region chaining decouple + D-10 atomic writes

**D-05 — current chaining loop (the collision site to modify)**
`src/allocation.r` (lines 1514-1543, `run_allocation_for_scenario`):
```r
  current_lulc_path <- initial_lulc_file[1]
  ...
  for (i in seq_along(year_starts)) {
    year_ant <- year_starts[i]; year_post <- year_ends[i]
    ...
    current_lulc_path <- run_allocation_one_timestep(   # <-- returns the NATIONAL mosaic today
      scenario = scenario, year_ant = year_ant, year_post = year_post,
      current_lulc_path = current_lulc_path,            # <-- next anterior = previous mosaic
      regions = regions, region_rast_path = region_rast_path,
      calibration_period = calibration_period, sim_dir = sim_dir, config = config)
    ...
  }
```
**The collision:** `run_allocation_one_timestep` returns `output_path = timestep_dir/posterior_<year>.tif` (the region-agnostic mosaic, `src/allocation.r:1804/1815`), and the loop feeds that mosaic back as the next anterior. Under per-region parallel jobs (D-01) every region job writes the same `posterior_<year>.tif` (clobber) and would chain on a single-region-extended mosaic.

**Fix shape (D-05):** when `ALLOCATION_REGION_FILTER` scopes a single region, the per-region chain must (a) NOT write/return the shared national `posterior_<year>.tif`, and (b) chain on its **own** region posterior. The region's own posterior already lives at:
- worker output: `region_work_dir/posterior.tif` (`src/dinamica_utils.r:861`, returned at `src/allocation.r:1782`)
- region work_dir: `timestep_dir/region_<suffix>/` (`src/allocation.r:830`)

The next anterior is built by masking the full-extent LULC to the region (`src/allocation.r:833-846`, `terra::mask` + `trim` → `anterior.tif`). Because region footprints are disjoint, a region only needs its own cells — so the per-region chain can pass forward its own `region_<suffix>/posterior.tif` (extended to full extent or re-masked) as `current_lulc_path` for the next timestep, and skip the `terra::merge` mosaic entirely (mosaic moves to the D-03 post-hoc job). The planner must verify the anterior-mask step still resolves the region's cells from a single-region posterior.

**D-10 — atomic writes (`.tmp.tif` → `file.rename`)**
All three `terra::writeRaster` sites in the timestep path currently write directly. Apply the tmp-then-rename pattern to each:
- per-region anterior write — `src/allocation.r:841-846`
- national mosaic write — `src/allocation.r:1805-1810`
- (plus the per-region posterior written by Dinamica via `run_allocation_dinamica` → `src/dinamica_utils.r:861` — verify whether that needs wrapping too)

Current direct-write block (the pattern to wrap), `src/allocation.r:1805-1810`:
```r
  output_path <- file.path(timestep_dir, sprintf("posterior_%d.tif", year_post))
  terra::writeRaster(
    mosaiced, output_path, overwrite = TRUE,
    wopt = list(datatype = "INT2U", gdal = c("COMPRESS=LZW")))
```
Target shape: write to `paste0(output_path, ".tmp.tif")`, then `file.rename(tmp, output_path)` only after a successful write, so a SIGKILL mid-write can't leave a half-written posterior the D-09 resume mistakes for complete. (No existing `file.rename`/`.tmp` precedent in the repo — `grep` finds none — so this is a new idiom; keep it local and uniform across the three write sites.)
