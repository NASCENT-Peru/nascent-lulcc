# Phase 03.3 Plan 02: Single-Source Writer + Inline Saturation Hook Summary

**Substantive bug fix for the ~1% allocation throughput observed in BAU smoke: refactored `setup_allocation_inputs()` to write the work_dir `trans_rates.csv` from a single filtered (no persistence, no zero-rate), id_trans-sorted data frame; promoted the missing-alloc_params `warning()` to `stop(call. = FALSE)`; removed the persistence/zero-rate skip in the TIF writer loop and added an all-NA fallback so the `%03d` prefix sequence Dinamica binds to is gap-free by construction; wired the inline `write_saturation_summary()` hook into `run_allocation_one_timestep()` and added `src/saturation_diagnostics.r` to the worker source list. After this plan lands, allocation throughput should jump from ~1% to the ≥90% per-transition floor (verified out-of-band by Wave 4).**

- **Single-source filter at allocation entry (D-02 / D-03 / ALLOC-06).** Replaced the `file.copy(trans_rate_src, trans_rates_dst, overwrite = TRUE)` + `read.csv(trans_rates_dst)` + `order(...)` sequence in `setup_allocation_inputs()` with an explicit `utils::read.csv(trans_rate_src, check.names = FALSE)` → base-R subset on `From*` != `To*` & `Rate` != 0 → `order(id_trans)` → `rownames(NULL)` → `utils::write.csv(filtered_df, trans_rates_dst, row.names = FALSE)`. - **alloc_params hard-stop (D-04 / ALLOC-08).** Promoted the `warning(log_msg(...))` block at the missing-alloc_params guard to `stop(log_msg(sprintf("Allocation params missing for active id_trans values (regenerate alloc_params for region %s period %s): %s", ...)), call. = FALSE)`. The alphabetic `%03d` sequence Dinamica binds to is now gap-free by construction even when a model produces no predictions for an active transition.

Produces `work_dir/saturation_summary.csv` and one `AUDIT stage=saturation` line per region at allocation time.
