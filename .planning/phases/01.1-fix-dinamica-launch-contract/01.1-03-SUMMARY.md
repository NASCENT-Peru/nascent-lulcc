## Decisions Made

- Inlined upstream `install_geospatial.sh` and `install_dinamica_pkg.r` verbatim in `%post` rather than vendoring them as `%files`. The upstream repo is a moving target and inlining keeps the `.sif` byte-reproducible from this `.def` alone.
- Used a `'CONF'` (quoted) heredoc for the `.dinamica_ego_8.conf` seed inside `%post` so the inner `"$VAR"` strings are not subject to %post expansion. This matches the upstream Dockerfile semantics (`cat <<EOF` would expand `${HOME}` in Docker, but we are writing to `/root/.dinamica_ego_8.conf` with a literal path and want literal interpolation strings inside the file).
- Kept the existing `org.opencontainers.image.source` label pointing at the upstream GitHub repo for provenance attribution, even though the bootstrap no longer pulls a GHCR image — the upstream is the source of truth for the inlined steps.
