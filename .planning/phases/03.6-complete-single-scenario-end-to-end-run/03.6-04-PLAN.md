<objective>
Build the durable capstone-evidence artifact (D-08): a run-manifest / checker that declares the
single-scenario run complete or incomplete from data, not log eyeballing. It:
1. Inventories `posterior.tif` across the FULL region × timestep matrix and asserts
   `count == regions × timesteps` (D-06).
2. Confirms the national `posterior_<year>.tif` exists for every timestep (D-03 output).
3. For every region × timestep, confirms the posterior is a valid GeoTIFF that DIFFERS from its
   anterior — the D-06 blocking bar (rules out the degenerate "nothing happened" case).
4. Aggregates per-(region,timestep) saturation from the 3.3 `saturation_summary.csv` surface and
   reports it as a quality signal — NOT a gate (D-07).
5. Runs lightweight trajectory plausibility QA (D-08b): aggregates per-class LULC areas across the
   chain via `terra::freq()`, flags hard all-one-class degeneracy (-> INCOMPLETE) and soft
   demand-mismatch vs `tools/simulation_lulc_areas_2060.csv` (-> warning).
6. Emits a single structured PASS / INCOMPLETE verdict and a manifest CSV.

Purpose: This is the proof Phase 3.6 is done. A single posterior existing does not prove a ~10-step
serial chain stayed sane to 2060 — the manifest is cheap insurance against silent drift.
Output: `scripts/run_manifest.r` (the checker) + `scripts/verify_allocation_run.sh` (thin operator
entry that runs it and surfaces the verdict).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| run outputs → manifest | The manifest reads operator-produced posteriors / saturation CSVs from trusted HPC scratch; read-only inventory, no untrusted/network input. |
| manifest verdict → operator/automation | A FALSE PASS (declaring an incomplete run complete) is the real risk — it would let a broken run be treated as the capstone. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-036-10 | Repudiation / Integrity | manifest verdict (false PASS) | mitigate | The verdict requires existence AND valid GeoTIFF AND differs-from-anterior AND count==regions×timesteps AND all national mosaics present AND no hard degeneracy; any failure forces INCOMPLETE and a non-zero exit, so an incomplete run cannot silently pass (Task 1). |
| T-036-11 | Tampering | half-written posterior counted as complete | accept | Upstream Plan 01 D-10 atomic writes ensure only fully-renamed posteriors exist; the manifest additionally re-validates each as a loadable GeoTIFF, so a truncated file fails valid_geotiff. |
| T-036-12 | Information Disclosure | scenario/region in file paths | accept | Inputs come from get_config() + regions.json (trusted), formatted via fixed transforms; no eval, operator-controlled paths. |
