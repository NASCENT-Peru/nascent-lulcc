<objective>
Close WR-07 and the smoke-verifier half of CR-03, and add the D-22 telemetry assertions.

WR-07: the Absolute-0 raster assertion multiplies the probability map by the zone selector and takes
the maximum, so a zone containing no cells at all yields `0` and passes, and an all-NA result is
converted to a pass by `if (!is.finite(mx)) mx <- 0`. `maps_checked` then reports N successful
checks when all N were vacuous — precisely the failure a smoke verifier exists to rule out.
CR-03: the forbidden-marker list contains `"missing value where TRUE/FALSE needed"` but not its
sibling `"argument is of length zero"`, which is the exact message the missing-`Prob_adjust_*`
defect produced.
D-22: the new telemetry must be asserted, not merely written.

Purpose: the verifier is the phase's regression gate for every future scenario and region. It must
not be able to say PASS about nothing.

Output: a verifier that fails on an empty zone, scans for both length-zero markers, cross-checks the
telemetry CSV against the AUDIT lines, and has an end-to-end fixture test.
</objective>
