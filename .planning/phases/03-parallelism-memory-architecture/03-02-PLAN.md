```r
write_nhood_tif <- function(anterior_path, pred_name, focal_matrices,
                            class_name_to_value, out_path) {
  anterior <- terra::rast(anterior_path)
  rast <- compute_single_nhood_raster(
    anterior = anterior, pred_name = pred_name,
    focal_matrices = focal_matrices, class_name_to_value = class_name_to_value
  )
  terra::writeRaster(
    rast, out_path, overwrite = TRUE,
    datatype = "FLT4S",
    gdal = c("COMPRESS=LZW", "TILED=YES",
             "BLOCKXSIZE=256", "BLOCKYSIZE=256",
             "BIGTIFF=IF_SAFER", "NUM_THREADS=1")
  )
  rm(rast, anterior); gc(verbose = FALSE)
  out_path
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Parent process -> future workers | Only plain R lists, vectors, and file paths may cross the future boundary; non-exportable external pointers must stay on one side |
| Parent process -> scratch filesystem | Parent writes neighbourhood TIFs that workers later reopen by path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Denial of Service | parent/worker memory duplication | mitigate | Preload read-only models once in the parent, materialize neighbourhood rasters to disk, and forbid the old in-worker raster cache |
| T-03-05 | Tampering | `nhood_paths` and preloaded model keys | mitigate | Construct file paths and model keys only from config-derived directories and region/transition metadata already present in the codebase; fail fast if any expected file is missing |
| T-03-06 | Denial of Service | strict-globals regressions | mitigate | Keep non-exportable objects out of captured globals and validate with `ALLOCATION_DEV_STRICT_GLOBALS=TRUE` before the smoke run |
</threat_model>
