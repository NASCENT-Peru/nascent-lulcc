<objective>
Close the engine half of GAP-2 (= `05.1-REVIEW.md` WR-01) and R51-IN-02 / R51-IN-03 in
`src/implement_spatial_interventions.R`.

GAP-2 (engine half): `.mask_inside_lut()` `:344` computes
`bad <- unique(v[!is.na(v) & v != 0 & v != 1])`. For an all-zero mask that set is EMPTY, so the
function returns an all-FALSE LUT with no stop. With `Prob_adjust_zone: Outside` the zone is then
the whole region — the exact impact this phase exists to prevent — and
`absolute_prob_adjust()` `:1053-1060` takes `sub_idx[!inside_flag]` with no log line.

THE SUBTLETY that shapes this whole plan: the LUT is built from `v`, the mask sampled at THIS
REGION's cells only. A region-level "no 1 in v" therefore cannot tell two very different masks
apart:

  - a mask that is all zero (or has values but no 1 anywhere)  -> a defect; STOP;
  - a mask that is validly 1-coded nationally but whose polygons miss this region -> legitimate
    (a national mask applied region by region); WARN, do not stop.

Stopping on the second would false-FAIL every region the mask does not cover. So: when `v` holds
no 1, run ONE national `terra::freq(m, digits = 12)` scan; stop only if the mask carries values and
none equals 1; otherwise fall through. The happy path (`v` holds a 1) pays nothing. The two traps
plan 05 documents apply here too: `freq()`'s default `digits = 0` rounds (use `digits = 12`), and an
EMPTY value table means all-NA, which is tolerated and must be tested BEFORE the no-1 test because
`any(logical(0))` is `FALSE`.

The non-fatal WARN cannot live inside `.mask_inside_lut()`: it needs the intervention id, the
region label and the zone, none of which that function receives. It is emitted by the caller,
`implement_spatial_interventions()`, immediately after the LUT is obtained. The sentence is frozen
by plan 05.1-04's verification step and must be emitted character for character.

R51-IN-02: the engine infers "categorical" from `extract()` happening to return a factor; the
pre-flight asks `terra::is.factor(m)`. If a future terra returned integer codes, `is.numeric(v)`
would be TRUE and the engine would silently compare level codes against `{0,1}`. Align the engine
onto `is.factor`.

R51-IN-03: `utils::head(bad, 5L)` truncates silently and `5L` is a bare literal.

Purpose: the engine and the pre-flight reject the same set of masks with the same wording, and a
mask that merely misses a region is told apart from a mask that is broken.
Output: a revised `.mask_inside_lut()`, one WARN line in the engine loop, and the fixtures whose
absence let GAP-2 ship.
</objective>
