## Verification scope

Per CONTEXT.md D-09, the Phase 03.3 acceptance scope is:

> **BAU × {andes, cuenca_del_amazonas, costa_peruana, selva_andina} × 2022 → 2026 first timestep.**

Wave 4 will iterate the four region labels above by invoking allocation with
`ALLOCATION_REGION_FILTER=<label>` once per region (or by running the full
allocation pass without a filter and asserting `saturation_summary.csv` exists
in each of the four region work_dirs under
`outputs/simulations/BAU/2026/region_<label>/`).

The `value` column maps each label to its 1-based `region_id` used by the
rasterised region mask written next to `regions.json`. The id is not required
for filename-based iteration; only the `label` strings are.
