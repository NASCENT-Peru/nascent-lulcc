### Task 1 — Cross-language mirror assertion test (commit `410a150`)

New file `tests/testthat/test-dinamica-launch-contract-mirror.R` (124 lines, 5
`test_that` blocks) re-resolves the Dinamica launch in BOTH languages against
identical inputs and asserts they agree:

- Sources `src/setup.r` + `src/utils.r` + `src/dinamica_utils.r` into a private
  `.env` via the verbatim loader pattern from `tests/testthat/test-dinamica-launcher.R`.
- Calls `.env$resolve_dinamica_launch(model_path="/abs/test.ego",
  backend="hpc", runtime_override="apptainer", probe_runtime=FALSE)` with
  `DINAMICA_EGO_8_HOME=/tmp/dinamica.sif`, `DINAMICA_BACKEND=hpc`, and a
  `withr::local_tempdir()`-scoped `HPC_SCRATCH_ROOT`.
- Invokes `bash scripts/smoke_test_dinamica.sh --dry-run --runtime apptainer
  --artifact /tmp/dinamica.sif --ego /abs/test.ego` via `system2()` with the
  same `HPC_SCRATCH_ROOT` propagated, captures stdout/stderr, and extracts
  the `resolved command :` line.
- Asserts BOTH sides include `--home`, `DINAMICA_EGO_8_TEMP_DIR=`,
  `bin/DinamicaEGO.sh`, `bash`, and the `.sif` path `/tmp/dinamica.sif`; also
  asserts the R-side `bash -c` payload (last `launch$args`) contains the
  absolute model path `/abs/test.ego` per D-106.
- Skip-guards both `resolve_dinamica_launch()` function-presence (so the file
  no-ops if the R source is unloaded) AND `bash` PATH availability (so the
  file no-ops cleanly on Windows hosts without Git-Bash / WSL).
