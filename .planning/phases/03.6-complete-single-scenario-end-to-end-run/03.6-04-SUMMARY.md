# Phase 03.6 Plan 04: Run Manifest + Verifier (Capstone Evidence) Summary

**A data-driven run manifest (`run_manifest.r`) that walks the FULL region x timestep matrix — asserting every `posterior.tif` exists, loads as a valid GeoTIFF, and DIFFERS from its anterior (the D-06 blocking bar), confirming every national `posterior_<year>.tif`, rolling up saturation (report-only) and `terra::freq`-based trajectory plausibility (hard degeneracy => INCOMPLETE, soft demand-mismatch => warning) — emits a single `STATE manifest verdict=PASS|INCOMPLETE` line + `run_manifest.csv` with a 0/non-zero exit, plus a thin operator wrapper (`verify_allocation_run.sh`) that surfaces the verdict and propagates the exit code.**

## Accomplishments

- **D-06 / D-08 / D-08b manifest (`scripts/run_manifest.r`):** resolves `simulation_output_dir`, the authoritative `simulation_year_steps` schedule (posterior years = `tail(year_steps, -1)`), the region labels from `regions.json` under `reg_dir`, and the saturation threshold — all from `get_config()`, nothing hardcoded. It builds the FULL `regions x posterior_years` matrix (`expected_cells = n_regions * n_timesteps`) and for EACH cell:
  - **EXISTENCE (D-06):** asserts `region_<suffix>/posterior.tif` exists and loads via `terra::rast` (errors caught, `valid_geotiff=FALSE` on failure).
  - **DIFFERS-FROM-ANTERIOR (D-06 blocking bar):** loads the cell's `anterior.tif` + `posterior.tif`, computes `changed_cells = terra::global(post != ante, "sum")`, and FAILS the cell (`differs_ok=FALSE`) when zero cells changed — ruling out the degenerate "nothing happened".
  - **SATURATION (D-07, report-only):** reads `region_<suffix>/saturation_summary.csv` (columns `floor_met`/`exempt`), aggregates `met/exempt/failed`, and emits one `AUDIT stage=saturation scenario=... region=... year_ant=... active=... met=... exempt=... failed=... threshold=...` line per cell using the exact `src/saturation_diagnostics.r:315-328` grammar. The verdict logic NEVER branches on saturation.
  - **PLAUSIBILITY (D-08b):** computes per-class areas via `terra::freq(posterior)`; flags HARD degeneracy (`n_classes <= 1` => contributes to INCOMPLETE) and accumulates the NATIONAL final-year per-class roll-up for the SOFT demand-mismatch check vs `tools/simulation_lulc_areas_2060.csv` (warning only, fraction comparison, 0.20 default tolerance).
  - Confirms the national `posterior_<year>.tif` exists for every timestep (`AUDIT stage=mosaic ... national_mosaic_exists=...`), writes `outputs/simulations/<scenario>/run_manifest.csv` (scenario, region, year, posterior_exists, valid_geotiff, changed_cells, differs_ok, saturation_met/exempt/failed, degenerate, n_classes, national_mosaic_exists), and emits the single `STATE manifest verdict=PASS|INCOMPLETE scenario=... cells=n/expected mosaics=m/t differs_failures=k degenerate=d sat_failed_total=f warnings=w` line, exiting `0` (PASS) / `1` (INCOMPLETE).
  - **Verdict (D-08):** INCOMPLETE if any cell fails existence/valid-GeoTIFF, any `differs_ok` is FALSE, any national mosaic is missing, `count != regions x timesteps`, or any hard degeneracy is present; otherwise PASS. This is the T-036-10 false-PASS mitigation — an incomplete run cannot silently pass.
- **D-08 operator wrapper (`scripts/verify_allocation_run.sh`):** a thin login/Rundeck-node entry (`set -euo pipefail`, NOT an SBATCH job) that accepts a scenario (positional | `ALLOC_SCENARIO` | default BAU), resolves `RSCRIPT_BIN` via the `hpc_common.sh` `allocation_env` boilerplate with a graceful fallback to a plain `Rscript` on PATH (modelled on `verify_phase3_smoke.sh`), runs `run_manifest.r "$SCENARIO"`, tees its output, surfaces the `STATE manifest verdict=...` line + the `run_manifest.csv` path, echoes a single `PASS`/`INCOMPLETE` line, and `exit "$MANIFEST_RC"` (captured via `PIPESTATUS`) so CI/operator gating works. It owns NO matrix-check logic — the R manifest is the single source of truth.

## Decisions Made

- **Defensive demand-table column detection.** The D-08b soft check finds a class-id column (`lulc`/`class`/`value`/`id`/`to`) and an area column (`area`/`cells`/`count`/`demand`) by name. `tools/simulation_lulc_areas_2060.csv` is authoritative only on HPC scratch and is NOT present in the repo checkout, so an absent table or unrecognised columns log a `status=demand_table_absent` / `status=demand_columns_unrecognised` line and SKIP the soft check — never an error, never INCOMPLETE (it is a warning-only surface by D-08b).
- **National final-year FRACTION comparison for the soft check.** The observed roll-up sums each region's final-year `terra::freq` counts into a national per-class total; the soft check compares observed FRACTIONS against demand FRACTIONS with a 0.20 default tolerance (`--tolerance` overridable). Fractions are robust to absolute-area / units drift between the freq cell-counts and whatever units the demand table uses.
- **Per-region work dirs are under `year_post`.** Confirmed `timestep_dir = file.path(sim_dir, as.character(year_post))` (`src/allocation.r:1633`) and `region_work_dir = file.path(timestep_dir, paste0("region_", region_suffix))` (`:863`), so the matrix walk reads `outputs/simulations/{scenario}/{year_post}/region_{suffix}/{posterior,anterior,saturation_summary}.{tif,csv}`. The AUDIT saturation line is keyed on the posterior year for continuity with the existing grammar.
- **Lighter source set than the assembler.** The manifest sources `setup.r` + `utils.r` + `saturation_diagnostics.r` (it needs `get_config()`, `log_msg()`, and the AUDIT-line conventions) but NOT `allocation.r` — it does no raster writing, so it does not need `write_raster_atomic`.
