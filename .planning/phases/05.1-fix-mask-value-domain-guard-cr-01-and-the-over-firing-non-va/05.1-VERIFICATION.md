## Ruling on the open discrepancy: R51-WR-03 naming

**R51-WR-03 is substantively closed. The naming inconsistency is cosmetic, not a gap.**

`tests/testthat/test-spatial-interventions-wiring.R` covers all three behaviours:

1. **Unreadable mask is a hard stop and all-NA is tolerated**, in one fixture (L642-684). `terra::freq` is mocked to raise for `nat_mask_2032` while `nat_mask_2028` is genuinely all-NA. It asserts exactly one line, starting `intervention mask: `, containing `values could not be read` and the mock message. It asserts the all-NA mask yields no line, no "has no cell equal to 1", and no "missing value where TRUE/FALSE needed".
2. **Unexpected freq shape** is reported as unreadable, not accepted (L686-704). Both masks are valid, so a line can only come from the shape handler.
3. **is.factor half** (L706-745, titled "REVIEW WR-03 (is.factor half)"). `is.factor` is mocked to raise on the staged masks while `freq` is stubbed to a well-formed all-1 table, which isolates the is.factor handler. It asserts "values could not be read" and that "is categorical/non-numeric" is absent.

Each block fails if the corresponding handler reverts to swallowing. The count discrepancy (two blocks carrying the literal id "R51-WR-03" against the prose "three") is a plan-text inconsistency. The executable `<verify>` and the code agree, and no behaviour is untested. Optionally rename the third block to include "R51-WR-03" for grep-ability. That is not required.
