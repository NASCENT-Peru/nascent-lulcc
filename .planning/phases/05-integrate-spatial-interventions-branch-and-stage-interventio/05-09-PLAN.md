<objective>
Close CR-02 (engine half), WR-10, IN-03 and IN-07: make the runtime mask lookup self-validating.
`.mask_inside_lut()` samples the mask with raw national cell numbers, which are only meaningful on
the exact grid that produced them, yet it never calls `terra::compareGeom()`, never checks
`terra::nlyr()`, and never validates `cell_index`. The review reproduced a shifted-CRS mask applying
an entirely fictional geography with no warning at all, and a smaller-extent mask degrading to a
truncated cell set behind an R warning that never reaches the worker log.

Purpose: the only geometry check in this phase lives in a standalone script wired into nothing. The
runtime must refuse a mis-gridded mask itself.

Output: a validating LUT builder, a `ref_grid_path` threaded from the allocation hook, and fixtures
that reproduce both CR-02 failure modes.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staged mask raster -> runtime cell-number lookup | A `.tif` on the staging filesystem is read and its raw cell numbers are trusted to index the national grid |
| filesystem between pre-flight and use | beegfs mounts can drop; a mask validated at Stage 7 can vanish before hour 3 of a region run |
| caller-supplied `cell_index` -> `logical(max(cell_id))` allocation | An unvalidated maximum drives a vector allocation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-31 | Tampering | `.mask_inside_lut()` geometry trust | mitigate | Required `ref_grid` plus `terra::compareGeom()` and `terra::nlyr()` assertions; a shifted-grid or multi-band mask is a hard stop, never a silent fictional cell set (CR-02) |
| T-05-32 | Tampering | `ref_cell_id` out of range | mitigate | Explicit range guard against `terra::ncell(mask)` before `terra::extract()`, replacing reliance on an R warning that never reaches the worker log (CR-02b) |
| T-05-33 | Denial of service | `logical(max(cell_index$cell_id))` | mitigate | `cell_index$cell_id` validated non-empty, non-NA and >= 1 before allocation; `max(integer(0))`, `logical(NA)` and zero-subscript mis-indexing are all rejected (WR-10) |
| T-05-34 | Tampering | TOCTOU between resolver `file.exists()` and LUT read | mitigate | `normalizePath()` wrapped so a vanished mask reports `intervention mask missing`, a marker the smoke verifier already treats as fatal (IN-07) |
| T-05-35 | Tampering | Stale LUT cache | mitigate | Cache key includes path, mtime, size and `cell_index` length, so an overwritten mask cannot be served from cache (IN-03) |
| T-05-SC | Tampering | package-manager installs | n/a | No dependency is added; no `install.packages`, npm, pip or cargo invocation appears in any task |
