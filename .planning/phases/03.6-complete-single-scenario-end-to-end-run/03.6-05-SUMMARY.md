## Operational findings resolved during the live run
- **ZALF ≠ EULER execution model.** Rundeck `salloc -N 1` reserves one node; `sbatch --partition=…` is scheduler-placed (not pinned to the SSH'd node). `detect_environment()` only returns `hpc` via `SLURM_JOB_ID`/EULER hostnames, so the launcher must run from a compute node (login nodes resolve `local_config`).
- **Predict was single-threaded** (cpus-per-task=40 + default multicore → `cores/workers=1`). Fixed: sequential strategy + whole-node cores (`8b7c1a0`), so the ranger predict uses all 160/80 cores.
- **Per-region memory routing** (`4e7d891`, `2517481`) from measured peaks: cuenca ~341GB, andes ~208GB, selva ~167GB → fat; costa ~110GB → highmem. selva OOM'd on highmem (R-side peak + Dinamica overhead > 188GB), which also cancelled the `afterok` mosaic — moved to fat.
- **Stray `na_counts_dynamic_predictors_2056.rds`** in the dynamic-predictor dataset root broke `arrow::open_dataset` at the terminal step (masked as furrr `In index: 1`). Operator removed it; added `open_parquet_dataset_guarded()` (`e69dd64`) that fails fast with a clear message on stray non-parquet files.
- **Scenario** switched BAU → NAT across the launch/verify path (`677f90b`).
