5. **Stage 6 (new)** — C++ source inlined as `<<'CPPEOF'` heredoc (portable; no `%files`

   ```bash
   g++ -shared -fPIC -std=c++17 -O2 \

       /tmp/dinamica_init_fix.cpp -ldl
   rm /tmp/dinamica_init_fix.cpp
   ```
6. **`%environment`** — added `export LD_PRELOAD=/usr/local/lib/dinamica_init_fix.so`.

### Why inline vs %files

The initial Task 1 commit used a `%files` section to copy `dinamica_init_fix.cpp` into the
container. Apptainer `%files` source paths are **CWD-relative at build time** — if the build
is invoked from any directory other than `$REPO_ROOT`, the path fails silently (or with a
cryptic `cc1plus: fatal error` at compile time). Iteration 2 surfaced this failure.
The fix (commit `0868bf5`) removed `%files` entirely and inlined the C++ source as a
single-quoted here-string (`<<'CPPEOF'`) directly in `%post` Stage 6. This is fully portable
regardless of build CWD.

## Task 2 — Operator Rebuild + Live Smoke Test

### Iteration 1 — Build failed: disk quota exceeded

**Error:** Operator ran `apptainer build --force dinamica-ego-8.sif ...` with a relative output
path. The relative path resolves to `$REPO_ROOT/dinamica-ego-8.sif` which lives under `$HOME`
on Euler. Euler home quotas (~15–50 GB) are exhausted during the final `Creating SIF file…`
step → `FATAL: disk quota exceeded`.

**Fix:** Build directly to `$DINAMICA_EGO_8_HOME` (scratch or project filesystem):
```bash
apptainer build --force "$DINAMICA_EGO_8_HOME" \
    dinamica/container/rocker-geospatial-dinamica.def
```

**New error surfaced from `%test`:** `System configuration file
"/root/.dinamica_ego_8_system.conf" does not exist` — the build itself succeeded but `%test`
ran `DinamicaConsole -version` and hit this new init check (previously hidden by the circular
init crash). The `.sif` that made it onto scratch from the partial build still had the old
crash pattern.

**Fix (commit `f5677e1`):**
- Added `touch /root/.dinamica_ego_8_system.conf` to `%post` Stage 5 (after conf seed).
- Added `touch "$STAGED_HOME/.dinamica_ego_8_system.conf"` to staged-home seeding in
  `scripts/smoke_test_dinamica.sh`.
- Added `file.create(system_conf)` for staged-home seeding in `src/dinamica_utils.r`.

### Iteration 2 — Build failed: %files CWD path

**Error:** `cc1plus: fatal error: /tmp/dinamica_init_fix.cpp: No such file or directory` —
the `%files` copy-in silently failed because the build was invoked from `$REPO_ROOT` but the
`%files` path resolution had a platform/Apptainer-version quirk. Stage 6's `g++` then found
no source file.

**Fix (commit `0868bf5`):** Removed `%files` section entirely; inlined the C++ source in `%post`
as `<<'CPPEOF'` (single-quoted; no shell expansion). The canonical reference copy in
`dinamica/container/dinamica_init_fix.cpp` is retained in the repo for readability but is
not consumed at build time.

Build succeeded this time. Smoke ran against the freshly built `.sif` and exited **5** — but
the D-107 error pattern this time was `Failed to create temporary directory` rather than
`std::exception`. The circular init crash is gone.

### Iteration 3 — Smoke exit 5: staged-tmp not bound

**Error (smoke log):**
```
Failed to create temporary directory, check your disk permissions or if you have free disk space
```

**Root cause:** On Euler, Apptainer does **not** auto-bind `/cluster/scratch` into the
container namespace when the `--home` flag is specified. The `DINAMICA_EGO_8_TEMP_DIR` env
var pointed to `$HPC_SCRATCH_ROOT/dinamica-tmp` which was invisible inside the container.
Dinamica's `getNewTemporaryDirectory()` failed → logged the error → exited 0 (Dinamica's
exit code is always 0) → D-107 grep caught the message → exit 5.

**Fix (commit `4b365d1`):** Added `--bind "$STAGED_TMP:$STAGED_TMP"` to every apptainer exec
invocation — no `.sif` rebuild required (runtime-only change):

| File | Change |
|------|--------|
| `scripts/smoke_test_dinamica.sh` | Added `"--bind" "$STAGED_TMP:$STAGED_TMP"` to `LAUNCH_CMD` array |
| `src/dinamica_utils.r` | Added `"--bind", paste0(staged_tmp, ":", staged_tmp)` to `container_args` |
| `dinamica/container/rocker-geospatial-dinamica.def` `%help` | D-104 example updated to include `--bind` |
| `dinamica/container/README.md` | D-104 example updated to include `--bind` |
| `docs/README_HPC.md` | D-104 example updated to include `--bind` |

The cross-language mirror test (`tests/testthat/test-dinamica-launch-contract-mirror.R`) was
verified to remain passing — it checks substrings, not exact argument order, so `--bind`
insertion does not break it.
