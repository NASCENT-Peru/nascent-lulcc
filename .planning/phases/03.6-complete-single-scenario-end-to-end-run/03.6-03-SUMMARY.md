# Phase 03.6 Plan 03: Post-Hoc National Mosaic Assembler Summary

**A standalone post-hoc assembler (`assemble_national_mosaic.r`) + thin SBATCH wrapper (`submit_assemble_mosaic.sh`) that, for every posterior year in `simulation_year_steps`, merges the per-region `region_<suffix>/posterior.tif` files into a national `posterior_<year>.tif` — the sole writer of that path under per-region parallel jobs, byte-comparable to the inline writer it replaces, and the launcher's `afterok` target.**

## Accomplishments

- **D-03 post-hoc assembler (`scripts/assemble_national_mosaic.r`):** lifts the inline merge/extend/writeRaster block (formerly in `run_allocation_one_timestep`) into a standalone script that iterates `tail(simulation_year_steps, -1)` (all posterior years, not a hardcoded one). For each year it builds the per-region `simulation_output_dir/<scenario>/<year>/region_<suffix>/posterior.tif` list (suffix = `gsub(" ","_",tolower())`, matching `allocation.r:862`), reads each with `terra::rast`, `terra::extend`s every region to the national `full_extent`, then `do.call(terra::merge, ...)` (single-region passthrough when only one region), and writes `posterior_<year>.tif` via the **Plan 01** `write_raster_atomic` helper with `datatype="INT2U"` / `COMPRESS=LZW` — so the national series is byte-comparable to the inline output and atomic (T-036-07). It frees rasters + `gc()` between years to bound memory.
- **D-05 sole-writer + refuse-partial guard:** because Plan 01 made single-region runs skip the national mosaic, this assembler is the SOLE writer of `posterior_<year>.tif` under parallel jobs. When any region's posterior is missing for a year, it emits one `AUDIT stage=mosaic ... status=missing region=<suffix>` line per missing region plus a `status=skipped` roll-up and **skips that year** — never writing a partial national mosaic (T-036-08; partial completeness is Plan 04's manifest job). One `AUDIT stage=mosaic ... status=ok` line is emitted per assembled year, plus a final `STATE stage=mosaic ... assembled=/skipped=/total=` roll-up.
- **D-03/D-04 thin wrapper (`scripts/submit_assemble_mosaic.sh`):** the `afterok` target the Plan 02 launcher already references by name. Modest SBATCH header (`--partition=highmem --cpus-per-task=4 --time=04:00:00 --output/--error=logs/assemble-mosaic-%j.*`) because `terra::merge` over a few posteriors is far lighter than allocation (no predictor preload, no Dinamica). Reuses the `hpc_common.sh` env-activation boilerplate verbatim (`setup_common_env` / `activate_env "$ENV_PATH"` with `ENV_NAME=allocation_env` / `RSCRIPT_BIN=$(verify_rscript "$ENV_PATH")`), reads the scenario from `ALLOC_SCENARIO` (default BAU) matching the launcher's `--export=ALL,ALLOC_SCENARIO=<scenario>`, echoes the resolved scenario, launches `assemble_national_mosaic.r "$ALLOC_SCENARIO"`, and exits with its code.

## Decisions Made

- **`full_extent` derived from the initial-LULC raster, not a per-year anterior file.** The plan's `<interfaces>` said the inline writer derived `full_extent` from the timestep's `current_lulc_path` (the anterior LULC for that timestep). In the multi-region inline path that `current_lulc_path` was the *previous national mosaic*, which itself carries the full initial extent — so the national grid is constant across timesteps and equals the initial-LULC extent. Resolving `full_extent` once from `config[["aggregated_lulc_dir"]]` for `simulation_start_year` (the same resolution the driver uses at `allocation.r:1494-1508`) is therefore byte-comparable to the inline writer AND avoids depending on an on-disk per-year national anterior that the post-hoc job (which only sees per-region posteriors) cannot assume exists. Per-region posteriors are all extended to this one extent, so the merge result is identical.
- **Assembler sources `src/allocation.r`** (in addition to `setup.r`/`utils.r`) specifically to reuse `write_raster_atomic` verbatim — a single source of truth for the `.tmp.tif -> file.rename` idiom rather than a copied local replica.
- **Wrapper scenario contract = `ALLOC_SCENARIO` (default BAU), passed positionally** — exactly matching the launcher's `--export=ALL,ALLOC_SCENARIO="$SCENARIO"` (verified in `submit_allocation_scenario.sh:189`).
