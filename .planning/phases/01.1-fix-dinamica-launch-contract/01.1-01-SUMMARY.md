# Phase 01.1 Plan 01: Fix Dinamica Launch Contract (R-Side) Summary

**One-liner:** Rewrote `resolve_dinamica_launch()` HPC branch to the supported `apptainer exec --home/--env … bash -c bin/DinamicaEGO.sh` shape (D-104/D-105/D-106) and replaced the half-version `exec_dinamica()` error check with a three-pattern post-hoc log grep (D-107/D-108) so `std::exception`-on-exit-0 failures finally stop the pipeline.

## What Was Built

### Task 1 — HPC apptainer launch shape (commit `692f880`)

`src/dinamica_utils.r:resolve_dinamica_launch()` HPC branch now produces:

```r
container_args <- c(
  "exec",
  "--home", staged_home,                                  # D-105
  "--env",  "DINAMICA_EGO_8_TEMP_DIR=<staged-tmp>",       # D-105
  artifact_path,                                          # the .sif
  "bash", "-c",
  "cd /opt/dinamica/usr && bin/DinamicaEGO.sh <flags> '<abs_model>'"  # D-104 + D-106
)
```

Pre-flight: fails fast with a clear `stop()` when `HPC_SCRATCH_ROOT` is unset on the HPC backend. Seeds `$HPC_SCRATCH_ROOT/dinamica-home/` and `$HPC_SCRATCH_ROOT/dinamica-tmp/` idempotently with an atomic `tempfile() + file.rename()` write of `.dinamica_ego_8.conf`. Local backend is byte-identical to the pre-rewrite state.

**Tests:** `tests/testthat/test-dinamica-launcher.R` rewritten — now 9 `test_that` blocks (was 5):
- D-104 launch shape assertions (`--home`, `--env`, `bash`, `-c`, `bin/DinamicaEGO.sh`, no DinamicaConsole).
- D-105 idempotent staged-home + staged-tmp + .conf seed (verifies exact 4-line content, verifies mtime preserved across calls).
- D-105 fail-fast on missing `HPC_SCRATCH_ROOT`.
- D-106 absolute model path enforcement (POSIX-or-Windows-absolute regex).
- Local backend invariants (no `--home`, no `--env`, `DinamicaConsole` is the command).
- Return-list keys contract (preserves the seven-key public surface).

### Task 2 — Three-pattern error detection (commit `50b3a6e`)

New file-scope constant + internal helper in `src/dinamica_utils.r`:

```r
DINAMICA_ERROR_PATTERNS <- c(
  "Dinamica EGO exited with an error",
  "terminate called after throwing",
  "std::exception"
)

.check_dinamica_post_run <- function(res, write_logfile, logfile_path) {
  # reads teed logfile when available; falls back to res$stdout+res$stderr
  # grepl(fixed=TRUE) against each pattern
  # stop() on any match OR non-zero exit, naming the matched pattern(s),
  # exit code (if non-zero), and the logfile path
}
```

`exec_dinamica()`'s old single-pattern stdout-only check was replaced with a single call to `.check_dinamica_post_run()`.

**Tests:** New file `tests/testthat/test-dinamica-error-detection.R` with 8 `test_that` blocks:
- DINAMICA_ERROR_PATTERNS contains the three D-107 strings.
- Each of the three patterns triggers `stop()` when exit=0 (D-107).
- Clean log + exit=0 stays silent.
- `write_logfile=FALSE` falls back to `res$stdout+res$stderr` (D-108).
- Stop-message format includes matched pattern names + logfile path (T-01.1-05).
- Non-zero exit fires even when log is clean.

## Deviations from Plan

**None — plan executed exactly as written.**
