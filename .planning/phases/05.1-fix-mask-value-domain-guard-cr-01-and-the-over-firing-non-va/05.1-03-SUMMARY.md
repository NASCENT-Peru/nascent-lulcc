Tooling note (not a deviation): the plan's task-1 `<automated>` one-liner embeds a `"^\\s*#"`
regex inside `Rscript -e '...'`, which this shell delivers to R as a single-backslash form that R
rejects — the same escaping trap plan 05.1-02 hit. The gates were therefore run from a scratchpad

the script additionally reports the all-lines counts alongside the non-comment counts so the
comment-vs-code distinction is visible rather than merely asserted.

## Open Items for a Future Phase (recorded, deliberately NOT fixed — D-07)

1. **`docs/README_HPC.md` contradicts itself about `--partition`.** Line 247-248 says the submit
   scripts request the whole reserved node (`#SBATCH --exclusive --mem=0`) and carry
   **no `--partition`**, so the Rundeck node size sets the memory limit; line 335 shows

   "No --partition: the Rundeck reservation places the job." Same defect as (1), same reasoning,

Both are documentation defects with the same blast radius as a code defect (they are the procedure
a future operator follows), so they should be closed in a follow-up rather than left indefinitely.
