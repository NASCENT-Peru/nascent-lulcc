# Phase 03.6 Plan 01: Allocation Driver Correctness (schedule + per-region decouple + atomic writes) Summary

**run_allocation driver now derives its 10 timestep pairs (2022->2060) from the authoritative simulation_year_steps schedule, chains single-region jobs on their own region posterior instead of the shared national mosaic, and writes every per-timestep raster atomically (.tmp.tif -> file.rename).**

## Accomplishments

- **D-11 schedule reconcile:** `run_allocation_for_scenario` replaces the `seq(start_year, end_year - step_length, by = step_length)` construction (9 steps, ends 2058) with `head/tail(config[["simulation_year_steps"]])` (10 steps, reaches 2060). The full null/empty + start-anchor + end-anchor + strictly-increasing validation block is ported verbatim from `simulation_trans_rates_prep.r:307-330` (same `stop()` wording), so the loop only requests `year_ant` rate tables that were actually generated. `filter_allocation_timesteps` and `profile_timestep_index` still subset the new pairs.
- **D-05 per-region chaining decouple:** the national-mosaic merge/extend/write block is now conditional on `length(region_inputs) > 1`. When `ALLOCATION_REGION_FILTER` scopes a single region (`length(region_inputs) == 1`), the timestep function returns that region's own `region_<suffix>/posterior.tif` (`posterior_paths[[1]]`) and skips the `terra::merge` mosaic entirely — so concurrent per-region jobs never clobber the shared `posterior_<year>.tif`, and each chain advances on its own posterior. National mosaic for the parallel-jobs case now comes only from the Plan 03 post-hoc assembler.
- **D-10 atomic writes:** added a local `write_raster_atomic(raster, final_path, wopt)` helper that writes to `paste0(final_path, ".tmp.tif")` then `file.rename()` into place (stop() on rename failure). The two R-side per-timestep writes — per-region anterior and national mosaic — route through it, preserving INT2U/COMPRESS=LZW wopt and overwrite semantics. A SIGKILL mid-write can now only leave a discardable `.tmp.tif`, never a half-written final posterior the D-09 resume would trust.
