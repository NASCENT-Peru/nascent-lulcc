<objective>
Build the capstone launcher (D-04) plus its single-region SBATCH job body. The launcher:
1. Resolves the region list from `regions.json` (config `reg_dir`) at run time.
2. Fans out one SLURM job per region with `ALLOCATION_REGION_FILTER=<region>` and a per-region
   highmem/fat partition + `--mem` (D-02 — bare sbatch defaults to the ~93GB compute partition
   and OOMs; andes peaked ~129GB for one timestep so ~256GB headroom).
3. Implements timestep-level resume (D-09): for each region, scans existing
   `region_<suffix>/posterior.tif` across `simulation_year_steps` and exports
   `ALLOCATION_YEAR_POST_FILTER` so the chain resumes from the next incomplete timestep instead
   of re-running hours of completed work.
4. Captures each region job id (`--parsable`) and queues a DEPENDENT
   (`--dependency=afterok:<id1>:<id2>:...`) national-mosaic-assembly job (the Plan 03 target).

Shape it to generalise to scenarios (Phase 4 S2) — parameterise the scenario — but run BAU only.

Purpose: Turn the per-region parallel decomposition (D-01) into a reproducible, documented,
resumable recipe instead of a hand-typed sbatch sequence in operator memory.
Output: `scripts/submit_allocation_scenario.sh` (launcher) + `scripts/submit_allocation_region.sh`
(single-region SBATCH job body).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator → launcher | Operator/env-supplied SCENARIO and region labels (resolved from regions.json) flow into sbatch --export and into shell-constructed paths. Trusted operator on HPC; regions.json is operator-controlled. |
| launcher → SLURM | The launcher submits jobs with per-region partition/mem; a wrong partition (bare compute) causes OOM, not a security breach. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-036-04 | Tampering | region label flowing into shell paths / sbatch --export | mitigate | Region labels come only from the trusted regions.json probe (not free operator text); the launcher quotes "$label" and derives region_suffix via fixed tr transforms — no eval of region text. Reject an empty region list (fail closed). |
| T-036-05 | Denial of Service | per-region job onto the ~93GB compute partition | mitigate | Default --partition=highmem in the job body and the launcher (D-02); never bare sbatch. A wrong-partition OOM is a run failure, not an external attack. |
| T-036-06 | Tampering | resume reads a half-written posterior as complete | accept | Mitigated upstream by Plan 01 D-10 atomic writes — the resume scan only sees fully-renamed posterior.tif files; no additional control needed here. |
