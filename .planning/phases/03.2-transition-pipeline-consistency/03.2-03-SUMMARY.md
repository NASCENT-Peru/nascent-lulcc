- Guards against missing artifacts with `file.exists()` checks — prints WARNING + remedy hint, sets the stage's id vector to `integer(0)`, and continues so the count table is always emitted (the empty-stage setdiff still raises FAIL, so missing artifacts cannot produce a false PASS).

## Decisions Made

- **Used `feature_selection_dir` (not `transition_feature_selection_dir`) for the Stage 2 path.** The plan's Task 1 action block explicitly authorized this substitution: "Before writing, confirm the correct config key … If the config key differs from `transition_feature_selection_dir`, update the `fs_dir` line accordingly." Confirmed against `config/local_config.yaml:33` and `src/transition_modelling.r:440`. This is not a deviation; the plan's prose flagged it as an expected substitution.
- **Added a defensive `names(fs_summary)` guard around the Stage 2 status filter.** `transition_feature_selection.r:616` saves `successful_transitions` to the RDS — the dplyr pipeline at line 600-606 drops the `status` column (`dplyr::select(-c(error_details, Rate, status))`). A literal `fs_summary$status == 'success'` filter would have crashed on real artifacts ("object of type 'NULL' is not subsettable"). The guard falls back to filtering by `region` alone when `status` is absent — correct because the source only writes the successful rows.
- **Added `--help` / `-h` handler as an early `quit(status=0)` path.** The orchestrator's prompt explicitly lists `Rscript scripts/audit_transition_pipeline.r --help` as a verification command and expects it to "show help text" without crashing. The `--help` handler runs before the missing-arg check, so a `--help` invocation prints usage and exits 0 even when other required args are absent.
- **Stage 4 audits only the first timestep (`simulation_start_year`).** Per RESEARCH.md, the rate-CSV row count is invariant across timesteps within a region, so checking the first one is sufficient. If a future operator wants to audit every timestep, the script can be extended with a loop over `simulation_year_steps`.
