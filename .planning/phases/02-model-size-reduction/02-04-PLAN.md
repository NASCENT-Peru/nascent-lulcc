<objective>
Create scripts/retrain_all_models.r — the utility script that orchestrates re-training of all ~140–160 transition-region model pairs using the new mlr3 pipeline (D-07, D-08). The script calls transition_modelling() directly (which already handles parallel execution via furrr::future_map() internally). It accepts --force, --dry-run, and --region flags. The --region flag performs real filtering: it reads viable_transitions_lists.csv, filters to rows where region_name == region_filter, writes a temp filtered CSV, and overrides config[["viable_transitions_lists"]] so that transition_modelling() only trains the requested region. It follows the established script skeleton pattern from scripts/run_transition_modelling.r.

Purpose: Gives the operator a single command to kick off mlr3 re-training of all transitions, replacing the now-obsolete tidymodels .rds files with mlr3 .qs files. The --region flag allows targeted re-training of a single region (e.g., for debugging or incremental migration). Without this, the operator must invoke transition_modelling() manually from an R session.
Output: New scripts/retrain_all_models.r that delegates to the already-tested transition_modelling() from 02-02.
</objective>

Region filtering implementation — filter viable_transitions by region_name BEFORE calling transition_modelling():
Since transition_modelling() reads viable_transitions_lists from config[["viable_transitions_lists"]] (a file path),
the filtering works by:
1. Reading the CSV at config[["viable_transitions_lists"]]
2. Filtering to rows where region_name %in% region_filter
3. Writing filtered rows to a temp file (tempfile(fileext = ".csv"))
4. Overriding config[["viable_transitions_lists"]] with the temp path
5. Calling transition_modelling() with the modified config

```r
if (!is.null(region_filter)) {
  viable_path <- config[["viable_transitions_lists"]]
  if (!file.exists(viable_path)) {
    cat(sprintf("ERROR: viable_transitions_lists.csv not found at %s\n", viable_path))
    quit(status = 1)
  }
  viable_all <- utils::read.csv(viable_path, stringsAsFactors = FALSE)
  viable_region <- viable_all[viable_all$region_name %in% region_filter, ]
  if (nrow(viable_region) == 0L) {
    cat(sprintf("WARNING: --region '%s' matched 0 rows in viable_transitions. Check region_name values.\n", region_filter))
    cat(sprintf("Available region_name values: %s\n",
      paste(sort(unique(viable_all$region_name)), collapse = ", ")))
    quit(status = 1)
  }
  temp_viable <- tempfile(fileext = ".csv")
  utils::write.csv(viable_region, temp_viable, row.names = FALSE)
  config[["viable_transitions_lists"]] <- temp_viable
  cat(sprintf("Region filter applied: '%s' — %d of %d viable transitions will be re-trained\n",
    region_filter, nrow(viable_region), nrow(viable_all)))
}
```

Dry-run mode — print expected transition-region pairs without training:
```r
if (dry_run) {
  viable_path <- config[["viable_transitions_lists"]]
  if (!file.exists(viable_path)) {
    cat(sprintf("Dry run: viable_transitions_lists.csv not found at %s\n", viable_path))
    cat("Cannot enumerate transition-region pairs without this file.\n")
    quit(status = 0)
  }
  viable <- utils::read.csv(viable_path, stringsAsFactors = FALSE)
  # Filter: non-self transitions, non-NA rate_2018_2022, exclude whole_map
  viable <- viable[
    !is.na(viable$rate_2018_2022) &
    viable$rate_2018_2022 != 0 &
    viable$region_name != "whole_map" &
    viable$from_class != viable$to_class,
  ]
  # Note: if --region was set, config[["viable_transitions_lists"]] already points
  # to the temp filtered CSV, so viable here is already region-filtered.
  cat(sprintf("[DRY RUN] Would re-train %d transition-region pairs:\n", nrow(viable)))
  for (i in seq_len(nrow(viable))) {
    cat(sprintf("  %s -> %s (%s)\n",
      viable$from_class[[i]], viable$to_class[[i]], viable$region_name[[i]]))
  }
  cat("\nRe-run without --dry-run to execute training.\n")
  quit(status = 0)
}
```
